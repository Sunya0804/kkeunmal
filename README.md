# 컴퓨터와 하는 끝말잇기

2018년에 문을 닫은 웹 게임 '컴퓨터와 하는 끝말잇기'와 비슷하게 다시 만들어 봤습니다. 표준국어대사전에 실린 명사만 쓸 수 있습니다.

## 실행

https://sunya0804.github.io/kkeunmal/ 에서 바로 할 수 있습니다.

내려받아서 하려면 `index.html`을 브라우저로 열면 됩니다. 서버나 설치는 필요 없습니다.

## 있는 것들

- 난이도 8단계. 1단계 컴퓨터는 한방단어를 쓰지 않고, 8단계는 이기는 단어만 냅니다.
- 치사한 짓 하기. 지금 낼 수 있는 단어를 전부 보여 주고, 단어마다 몇 턴 안에 이기는지 지는지 알려 줍니다.
- 전체 DB. 단어 21만 개를 훑어보거나, 어떤 단어 뒤에 올 수 있는 단어를 찾아볼 수 있습니다.
- 한방단어 목록과 게임 방법 안내.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html`, `ui.js` | 게임 화면 |
| `db.html`, `db.js` | 전체 DB 화면 |
| `guide.html` | 게임 방법 안내 |
| `hanbang.html` | 한방단어 목록. `tools/build_hanbang.py`가 만듭니다. |
| `engine.js` | 규칙 검사, 두음법칙, 승패 분석, 컴퓨터의 단어 선택 |
| `cheatview.js` | 이을 수 있는 단어를 유리한 순서로 그립니다. |
| `definitions.js` | 뜻풀이를 필요한 만큼만 불러옵니다. |
| `data/` | 단어 목록과 뜻풀이. `tools/build_words.py`가 사전 XML에서 뽑아냅니다. |
